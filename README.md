# دليل تكامل نظام يزل (Vercel + Firebase)

هذا الدليل يشرح كيفية عمل النظام وتكامله بين منصة الاستضافة (Vercel) وقاعدة البيانات (Firebase).

## 1. بنية النظام (Architecture)
يعتمد نظام "يزل" على بنية حديثة تفصل بين واجهة المستخدم والخدمات الخلفية:

*   **Frontend (Vercel):** يتم استضافة واجهة React (المبنية باستخدام Vite) على منصة Vercel. هي المسؤولة عن عرض الشاشات ومعالجة تفاعل المستخدم.
*   **Backend (Firebase):** يعمل كـ "Backend as a Service". يوفر قاعدة البيانات (Firestore) ونظام التوثيق (Authentication).

## 2. كيفية الربط الأمني (Security & Environment Variables)

يتم الربط بين المنصتين بشكل آمن عبر الخطوات التالية:

### أ. متغيرات البيئة (Environment Variables)
في بيئة التطوير، نستخدم ملف `.env`. عند النشر على **Vercel**، يتم إدخال هذه القيم في لوحة تحكم Vercel (Settings > Environment Variables).
*   يتم استخدام بادئة `VITE_` (مثل `VITE_FIREBASE_API_KEY`) لكي يتعرف عليها محرك Vite ويقوم بتضمينها في الكود البرمجي للواجهة.

### ب. ملف الإعدادات (`firebase-applet-config.json`)
يحتوي هذا الملف على المعرفات العامة لمشروع Firebase (مثل `appId`, `projectId`). هذه المعرفات ليست سرية بحد ذاتها، بل تعمل كـ "عنوان" ليوجه التطبيق إلى مشروعك الصحيح.

### ج. قواعد الحماية (`firestore.rules`)
الأمن الحقيقي يكمن في Firebase. حتى لو حصل شخص ما على مفتاح API، لا يمكنه القراءة أو الكتابة إلا إذا وافق **نظام قواعد Firestore** على ذلك. نحن قمنا ببرمجة القواعد لتسمح فقط للموظفين والمدراء بالوصول للبيانات.

## 3. آلية النشر (Deployment Pipeline)

عملية النشر تتم بشكل آلي (CI/CD):

1.  **الربط:** يتم ربط مستودع الكود (GitHub) بمنصة Vercel.
2.  **التفعيل:** عند القيام بأي "Push" للكود، تقوم Vercel تلقائياً ببدء عملية البناء (`npm run build`).
3.  **الاستضافة:** يتم تحويل الكود إلى ملفات ثابتة (Static Files) ونشرها على شبكة توزيع محتوى (CDN) عالمية لضمان السرعة.
4.  **التصاريح:** يتم منح Vercel تصريح الوصول لـ Firebase من خلال مفاتيح الربط الموجودة في متغيرات البيئة.

## 4. حالة النظام الحالية

*   **قاعدة البيانات:** تم تجهيز Firestore بالكامل، وتفعيل التوثيق (Auth)، ونشر قواعد الحماية.
*   **الشاشات:** تم الانتهاء من جميع الشاشات الأساسية (تسجيل الدخول، لوحة التحكم، إدارة العملاء، المهام، السجل المالي مع تصدير PDF، والمصروفات).
*   **المزامنة:** جميع البيانات الآن متزامنة لحظياً (Real-time) بين جميع الموظفين المتصلين.
